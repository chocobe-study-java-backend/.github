# Java 백엔드 스터디

- Java 기반 백엔드 스터디 실습 프로젝트들을 관리하기 위한 Organization 입니다.
- 인프런 김영한 강사님의 로드맵에 대하여 Github Project 로 구성합니다.



<br /><hr /><br />



## 저장소 네이밍 규칙

- 예시: [roadmap-01-01]-실습-프로젝트-이름
- 접두사: `[roadmap-로드맵번호-실습번호]-`
- 접두사 이후, 실습 프로젝트 이름
- 로드맵 이외의 Java 백엔드 관련 저장소는 네이밍 규칙을 사용하지 않습니다.
